Boh Face Kit

Everything for the ChatGPT faces job, in one place. 6 faces × 3 Bohs = 18 images. Only the face changes, so every item students bought still fits.

How to do each one

  1. Open a new ChatGPT chat for every image.
  2. Upload the right Boh picture (below). Tap Download next to it.
  3. In ChatGPT, tap the image → Select. Paint over only the eyes, eyebrows and mouth. Not the hair, ears or hijab.
  4. Tap Copy on one face card below and paste it into ChatGPT.
  5. Save the result with the file name shown on the card.

Do the first card first and send it to Claude before doing the rest.

Reject and redo if

  • The hair, hijab or ears changed
  • Colors shifted, or the style got "improved"
  • Anything was added: background, shadow, sparkles, text
  • The picture got cropped or resized

Tip: put the result next to the original. If you can spot a difference outside the face, it's a redo.
